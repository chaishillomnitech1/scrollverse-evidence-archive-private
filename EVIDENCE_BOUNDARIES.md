# Evidence Boundaries and Operating States

## Operating states

| State | Meaning |
|---|---|
| **Available now** | A public source or a documented local interface/result can be inspected now. |
| **Research** | A topic, connection, or capability is being studied; no external outcome is implied. |
| **Requires owner release** | A private account record, asset, authorization, filing, provider action, or external release requires explicit owner-controlled evidence. |

## Evidence categories

| Category | Meaning |
|---|---|
| **First-party account** | The owner’s own statement about intent, work, experience, or interpretation. |
| **Public source statement** | Text or metadata visible on a public page at the time of review. |
| **Documented local result** | A locally observed route, validation command, or test result recorded with its operating boundary. |
| **Unverified external claim** | An assertion that needs an independent source, authorized provider record, official filing, or other direct evidence. |

## Correction path

Every record can be updated by adding the exact source URL, export, screenshot, version, date, or authorized provider result that clarifies it. A correction supplements the existing entry instead of silently replacing the prior record.
