# ScrollVerse Evidence Archive

This private repository is a source-labeled working archive for **ScrollVerse**. It preserves a practical review trail for public sources, first-party project context, documented local validation, and evidence gaps.

## Purpose

The repository is designed for inspection rather than persuasion. Each record distinguishes between a first-party statement, a public source, a documented local result, and an external outcome that needs its own record.

## Included records

| File | Scope |
|---|---|
| `EVIDENCE_BOUNDARIES.md` | Operating-state labels, source categories, and exclusions. |
| `CAPABILITY_RECORD.md` | First-party capability record linked to documented local validation and public-source gaps. |
| `PUBLIC_SOURCE_INDEX.md` | Public GitHub and YouTube source-index notes. |

## Exclusions

This repository does **not** contain private keys, credentials, wallet material, personal inbox data, private Google/YouTube account records, protected third-party intake, financial-account information, or code that performs a deployment, payment, filing, token action, or external account action.
